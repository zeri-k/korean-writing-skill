# 발표 노트와 대본

PPT의 발표 노트나 별도 발표 대본을 작성하거나 교정할 때 적용한다. 슬라이드 본문만 작성하는 작업에는 이 기준을 추가로 읽지 않는다.

- 격식 있는 어휘를 사용하며 소리 내어 읽기 자연스러운 서술형으로 작성한다. 청중에게 설명하거나 정중하게 요청하고 명령조는 사용하지 않는다. 읽을 문장에는 Markdown 굵게 표시를 넣지 않는다.
- 화면의 위치만으로 대상을 지시하지 않는다. 이름이나 번호와 핵심어를 함께 사용하고, 슬라이드 순서가 변경되면 참조도 수정한다. 사례는 해당 사례를 식별할 수 있는 이름으로 지칭한다.
- 화면 문구를 되풀이하는 데 그치지 않고 필요한 배경, 이유와 적용 조건을 설명한다. 근거 없는 내용을 추가하거나 청중의 지식 수준을 단정하지 않는다.
- 화면과 노트의 수치, 용어, 조건과 결론을 대조한다. 발표하기 쉽게 압축하면서 주장 강도나 요청의 의미를 변경하지 않는다.

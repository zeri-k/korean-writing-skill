# 문서 종류별 형식

문서의 초안이나 기존 제목, 불릿과 본문의 문체 및 형식을 작성하거나 교정할 때 적용한다. 사용자 템플릿과 보존할 기존 양식이 우선한다. 같은 목록에서 같은 종류의 내용을 설명하는 항목은 문장 끝맺음과 표기를 맞춘다. 이때 과거에 수행한 일을 현재 진행 중인 일로 바꾸는 등 원문의 시제를 변경하지 않는다. 교육, 보안, 업무 공유 같은 주제와 목적은 독자와 설명 깊이를 정하는 데 반영한다. 단일 문장의 교정에 문서 전체의 형식을 강제하지 않는다.

내용은 문서 목적과 문항의 요구에 맞춰 선택한다. 역할과 수행 사실을 소개하는 문장에 목표, 포부나 자기평가를 관행적으로 덧붙이지 않는다. 문서 목적상 필요하거나 사용자가 포함하도록 요청한 경우에 작성한다.

| 문서 종류 | 기본 형식 |
|---|---|
| 보고서 | 판단한 내용과 그 판단을 뒷받침하는 자료나 관찰 결과를 함께 설명한다. 제목은 명사형을 기본으로 하고, 결과와 조치 목록은 조건을 보존할 수 있으면 명사형으로 정리한다. 조직의 양식이 지정한 종결형과 개조식은 유지한다. |
| PPT | 제목은 명사형, 본문은 짧은 서술문이나 명사형 불릿을 기본으로 한다. 서로 다른 행동이나 판단은 별도 문장이나 항목으로 구분한다. 짧은 표현에도 격식을 적용하고 해석에 필요한 조건과 근거를 남긴다. |
| 매뉴얼과 가이드 | 행동, 조건과 확인할 결과를 읽는 순서에 맞춰 서술한다. 선택 가능한 대안과 연속 단계를 구별한다. 실행할 명령과 주변 설명의 문체를 구분한다. |
| 메일 | 용건, 필요한 설명과 요청하는 행동을 분명하게 작성한다. 부탁이나 권고를 의무로 바꾸거나 의무를 선택 사항으로 바꾸지 않으며, 사용자가 지정한 문체를 따른다. |
| 회의록 | 논의 내용, 결정 사항과 후속 행동을 구분한다. 짧은 기록은 명사형으로 작성할 수 있다. 발언과 확정된 결정을 구별하고 담당자와 기한은 확인된 범위에서 적는다. |
| 규정과 지침 | 대상, 조건과 행동이 분명한 `~한다` 형태의 서술을 기본으로 한다. 의무, 권고와 예외를 구분한다. 이 스킬의 지침 문서도 같은 형식을 사용한다. |

제목과 요약은 실제 내용과 범위를 가리켜야 한다. 상위 제목을 의미 없이 반복하지 않고, 명사형으로 압축하면서 조건을 삭제하지 않는다. 일반 대화에 제목이나 불릿이 있다는 이유로 보고서 형식을 적용하지 않는다. 표에 없는 문서는 요청 목적과 기존 양식에 맞춰 작성한다.

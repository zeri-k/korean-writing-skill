# 문장과 문단 교정

문단 작성, 번역과 요약, 어순과 문장 관계를 검토할 때 적용한다. 예시는 문맥 판단을 돕는 자료이며 단어의 일괄 치환이나 금지 목록으로 사용하지 않는다.

## 대상과 동작

- 상태, 구조, 관계, 영향 등의 추상 명사만으로 끝나는 설명은 실제 대상과 동작을 확인해 작성한다. `상태가 유지됩니다`라면 무엇이 남고 어떤 행동이 계속 가능한지 설명한다. 정확한 기술 개념으로 사용된 추상 명사는 유지한다.
- `~라는 점이 중요합니다`, `~을 보여 줍니다` 등의 평가가 결론을 가리면 확인된 사실과 성립 조건을 먼저 제시한다. 진행 안내나 중요하다는 강조만으로 설명을 끝내지 않는다.
- 적절한, 충분한, 효과적인 등의 수식어가 기준을 대신하면 실제 조치나 비교 조건을 제시한다. 필요한 정보가 없으면 수치와 조건을 만들어 구체화하지 않는다. 의인화와 과장은 확인된 동작으로 정리하되 기술 용어인 신뢰나 실제 영향까지 제거하지 않는다.

## 어순과 연결

- 번역은 대상, 행동, 조건과 결과의 의미를 파악한 뒤 한국어 어순으로 다시 작성한다. 원문의 순서와 구조를 보존하는 작업에서는 해당 기준을 우선한다. 영어의 명사화나 피동을 그대로 따르지 않으며 `요청의 검증을 수행합니다`는 같은 의미라면 `요청을 검증합니다`로 정리한다.
- 격식 있는 어휘를 선택하면서 문장 전체의 호응도 확인한다. 주어, 목적어와 서술어, 수식어의 대상을 분명히 한다. 문맥상 명확한 주어는 생략할 수 있으나 독자가 행위자를 추정해야 하는 생략은 보완한다.
- 분석 결과가 다음 동작의 근거나 입력이 되는 경우에는 그 연결을 보존한다. 압축으로 관계가 불분명해졌다면 확인된 근거·도구·동작을 연결해 설명하되, 문맥상 분명한 과정까지 반복하거나 확인되지 않은 단계와 도구를 추가하지 않는다.
- 원인, 조건, 예외와 결과가 얽히면 논리 단위로 나눈다. 글자 수, 절의 개수나 능동태 여부만으로 문장을 판정하지 않는다. 문단의 화제가 불필요하게 오가지 않도록 연결한다.
- `또한`, `따라서`, `반면` 등의 연결어는 실제 관계를 밝힐 때 사용한다. 목록과 병렬 문장은 같은 질문에 답하도록 구성하며 대상, 규모, 수단과 통제처럼 다른 분류 기준을 섞지 않는다. 비교 구조를 맞추면서 실제 차이를 지우지 않는다.

## 반복과 군더더기

- 정보나 강도를 더하지 않는 부사와 겹치는 표현은 줄인다. `실제`도 강조만 더하면 생략하되, 모의훈련과 실제 사고처럼 대상을 구분하는 경우에는 유지한다. 빈도, 의무나 범위를 나타내는 `항상`, `반드시`, `모든`까지 강조어라는 이유로 삭제하지 않는다.
- `~에 대한`, `~을 통해`, `~에 의해`, `~에 있어서`, `~의 경우`와 조사 `의`가 관계를 가리거나 문장을 늘리면 직접적인 조사와 동사로 정리한다. 특정 표현의 등장만으로 오류를 판정하지 않는다.
- 동작을 직접 설명할 수 있으면 부정형으로 우회하지 않는다. 부재 자체가 원인이나 조건이면 유지한다. 사용하지 않는 기준만 나열하지 않고 실제 사용하는 기준을 설명한다.
- 지시어가 가리키는 대상을 하나로 식별할 수 없으면 이름으로 정리한다. 명확한 지시어까지 제거해 같은 이름을 반복하지 않는다. 비슷해 보여도 의미가 다른 용어는 합치지 않는다.
- 새로운 정보가 없는 재요약, 문서 자체의 소개, 편집 의도 설명과 구호를 줄인다. 필요한 개요, 공개 범위, 해석의 한계, 요청받은 변경 보고와 직접 인용은 보존한다.

교정 후 원문을 모르는 독자의 관점에서 대상과 관계를 다시 확인한다. 어휘 변경에 따른 조사와 호응, 압축하며 사라진 조건, 연결된 제목과 참조를 대조한다. 검색은 검토 후보를 찾는 데 사용하며 문맥 확인을 대신하지 않는다.

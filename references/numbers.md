# 수치와 비교 기준

집계 수치, 비율, 증감률과 분포를 작성하거나 비교할 때 적용한다. 포트, 버전, 식별자와 코드 안의 숫자는 그 자체로 이 검토의 대상이 아니다.

- 무엇을 센 값인지 대상, 단위와 기간을 밝힌다. 비율은 분모와 모집단을 확인할 수 있게 제시한다. 표 머리글이나 인접 설명에서 이미 명확한 정보는 반복하지 않는다.
- 신고 건수와 처분 건수처럼 집계 기준이 다른 수치를 같은 모집단으로 취급하지 않는다. 포함 관계가 확인되지 않았다면 하나를 다른 하나로 나눈 값을 처리율로 제시하지 않는다. 증감률의 비교 대상과 기간도 확인한다.
- 일부 항목이나 공개된 자료만으로 전체 분포를 설명하지 않는다. 제시 범위를 밝히며 합계가 100%가 아니라는 이유만으로 비율을 모두 건수로 바꾸지 않는다. 차이가 생긴 이유는 근거에서 확인한 범위만 설명한다.
- 외부 수치는 원자료의 대상, 단위, 기간, 분모와 모집단을 대조한다. 직접 계산한 값은 원자료에 제시된 값과 구분하고 계산 기준을 확인한다. 확인되지 않은 기준을 채우지 않으며 필요한 한계를 밝히거나 사용을 보류한다.
- 잠재적 영향 범위와 확인된 피해 규모를 구분한다. 표, 본문과 요약이 같은 값과 이름을 사용하고 서로 다른 지표를 혼용하지 않는지 확인한다.

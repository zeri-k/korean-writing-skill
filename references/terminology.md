# 기술 용어와 대상의 이름

기술 개념을 설명하거나 용어, 약어와 대상의 역할을 교정할 때 적용한다. 공통 스타일의 기본 어휘를 따르되 표현을 바꾸면서 기술적 의미를 변경하지 않는다.

## 표기와 풀이

- 기술 용어는 대상 분야와 독자에게 통용되는 한국어, 영어 또는 한글 음역을 선택한다. 사용자와 프로젝트의 명시적인 표기를 우선한다. 공식 번역어가 있어도 문맥에서 생소하거나 뜻을 오해하기 쉬우면 원어나 통용되는 음역을 사용한다. 통용 여부를 확인하기 어렵다면 원어를 유지하고 임의의 번역어·음역을 만들지 않는다. 같은 개념의 표기는 문서 안에서 일관되게 사용한다.
- 용어와 약어의 풀이 여부는 예상 독자와 문맥에 따라 판단한다. 독자에게 익숙하고 의미가 분명하면 풀이를 생략할 수 있다. 생소하거나 뜻이 모호하면 확인된 전체 이름과 필요한 동작·역할을 첫 등장 가까이에 설명한다. 원어나 전체 이름을 병기한 것만으로 개념이 설명됐다고 보지 않는다. 화면과 코드에 쓰인 이름을 대조하는 데 필요한 원어는 유지하고, 확인하지 못한 약어의 뜻과 기관의 역할을 추정하지 않는다.

## 기술적 차이

- 인증과 인가, 암호화와 해시 및 인코딩, 서명과 암호화, 식별과 인증, 탐지와 차단, 검증과 정제, 직렬화와 암호화, 재시도와 재전송을 유의어로 취급하지 않는다. 트랜잭션, 멱등성과 동시성 제어도 각각의 역할을 유지한다. 하이재킹, 신원 확인과 반출처럼 정확한 전문 용어를 다른 개념으로 치환하지 않는다.
- 제품, 라이브러리와 프로토콜의 상수나 기능명은 일반 개념과 구분한다. 한 제품의 동작을 모든 환경의 원칙으로 확대하지 않는다. 코드, 식별자와 공식 명칭의 보존 기준을 따른다.
- `막는다`, `보장한다`, `해결한다`가 실제 범위를 넘는지 확인한다. 영향을 줄이는 통제와 발생을 항상 방지하는 통제를 구분한다. 의미가 불명확하면 동의어를 찾는 데 그치지 않고 근거에서 실제 동작을 확인한다.

## 어휘 선택의 조건

- 권한 설명에서 `특권`이라는 표현은 사용하지 않는다. 구체적인 권한을 설명할 때는 확인된 권한 이름이나 식별자와 허용 동작을 함께 설명한다. `파일 백업 권한(SeBackupPrivilege)`, `파일 쓰기 권한`, `서비스 구성 변경 권한`처럼 대상과 동작을 구체화한다. 정확한 권한을 확인하지 못했다면 근거를 확인하거나 미확인 사항으로 남기며 권한 이름·식별자·지원 범위를 추정하지 않는다.
- 설정의 변경, 구조의 변형, 대응하는 값의 치환과 형식의 변환을 구별한다. `만들다`의 대상이 결과물인지, 어떤 상태를 초래한다는 의미인지 판단하고 원인과 결과를 유지한다.
- 반환된 값과 외부에 노출된 정보, 의도적 제거와 누락, 정상 전달과 유출을 구분한다. 토큰 값이 남아 있다는 사실만으로 유효하다고 설명하지 않는다.
- `데이터가 남아 있다`는 설명을 고칠 때 원문에 없는 `데이터를 삭제해야 한다`거나 `데이터 삭제에 실패했다`는 의미를 추가하지 않는다. 불명확한 수량을 다수, 두 번 이상이나 중복으로 단정하지 않는다. 실행을 시도하거나 시험했다는 의미도 유지한다.
- 운영체제의 프로세스를 절차로 변경하지 않는다. 일반적인 질문과 DB 쿼리를 구별하고 코드의 `token`은 보존한다. `사용자 정의 오류 페이지` 같은 고정 표현은 사람 지칭 선호 때문에 변경하지 않는다.

## 저장 대상 구분

Git 사용이 확인된 경우에 Git repository를 사용한다. 같은 문맥에서 대상이 명확하면 repository로 줄일 수 있다. 형상관리 체계 전체와 개별 repository를 구별한다. 시크릿 관리 대상은 제품명이나 시크릿 관리 시스템, Java 키스토어는 키스토어로 지칭한다. 데이터베이스, 파일 스토리지, 앱 로컬 스토리지와 브라우저 스토리지를 혼용하지 않으며 확인된 `localStorage` 같은 명칭은 유지한다.

Terraform의 상태 보관 구성은 Terraform 상태 저장 백엔드로 설명한다. `state 파일을 보관하는 S3 버킷`은 S3 사용이 확인된 경우에만 쓴다. 대상을 구체화하기 위해 비밀키의 위치, 암호화 여부나 시스템 분리를 추정하지 않는다. 정확한 용어가 생소하면 뜻을 설명하며 좁은 개념으로 임의 대체하지 않는다.

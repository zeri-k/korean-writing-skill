# 코드와 절차의 연결

실행 순서, 코드와 설명의 대응, 단계 사이의 입력과 결과를 작성하거나 검토할 때 적용한다. 단순히 코드나 명령을 보존하는 번역에 절차 재설계를 추가하지 않는다.

- 실행할 행동과 필요한 조건, 입력을 얻는 위치와 확인할 결과를 읽는 순서에 맞춰 설명한다. 실제 명령 문자열은 보존하고 주변 설명은 명령조를 피한 서술형으로 작성한다.
- 코드나 절차를 나누면 연속 단계인지 대안인지 구분한다. 뒤 블록이 앞 블록의 변수나 결과를 사용하면 의존 관계를 설명한다. 번호와 `이어짐` 표시는 일치시키되 특정 기호를 강제하지 않는다.
- 코드, 주석과 본문의 대상과 동작이 일치하는지 대조한다. 예시와 설명이 다르면 단어만 교체해 불일치를 감추지 않는다. 기술 내용의 정정이 필요하면 적용 조건과 근거를 확인하고 요청 범위에서 처리한다.
- 성공 조건과 실패 시 관찰할 결과를 혼동하지 않는다. 일부 단계의 실행만으로 전체 절차가 완료됐다고 표현하지 않는다. 검증하지 못한 동작과 미해결 조건은 구분해 알린다.

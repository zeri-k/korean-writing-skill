# 맞춤법 오류와 허용 표기 판단

맞춤법·띄어쓰기를 상세히 검토하거나, 교정 중 발견한 표기가 오류인지 허용되는 표기인지 판단할 때 적용한다.

- 규정에 어긋난 표기, 규정상 허용되는 표기, 문서에서 선택한 표기 방식을 구분한다. 허용 표기를 문체 선호만으로 오류라고 보고하지 않는다. 여러 표기 중 하나로 통일할 필요가 있으면 일관성 개선으로 설명한다.
- 불확실한 단어·띄어쓰기는 국립국어원의 현재 규정과 해설, 표준국어대사전의 해당 뜻을 확인한다. 규정의 적용 조건과 붙여 쓰기 허용 범위까지 확인하며, 겉모양이 비슷한 예시를 다른 구성에 그대로 적용하지 않는다. 확인할 수 없으면 오류로 단정하지 않고 판단이 필요한 표현과 이유를 남긴다.

## 자주 혼동하는 범위

| 구분 | 판단할 내용 |
|---|---|
| 의존 명사와 조사 | `할 수 있다`, `아는 것`, `먹을 만큼`은 단어를 구분해 쓴다. `나만큼`, `이것뿐`처럼 조사가 붙은 구성과 구분한다. `수`·`것` 등의 문자열만 찾아 일괄 치환하지 않는다. |
| 숫자와 단위 명사 | `10 개`·`10개`, `3 명`·`3명`은 모두 허용된다. 일반 수량을 한글로 적은 `세 권`과 같은 구성을 숫자 표기와 혼동하지 않는다. |
| 보조 용언 | 띄어 쓰기가 원칙이고 붙여 쓰기는 허용되는 구성에 한한다. `읽어 보다`·`읽어보다`와 달리 `하고 있다`는 띄어 쓴다. 앞말의 구성이나 조사 개입에 따른 예외, 한 단어로 등재된 표현도 확인한다. |

이 표는 전체 맞춤법 규칙을 대신하지 않는다. 의미·사실·격식과 코드·식별자·인용의 보존은 스킬의 공통 기준을 따른다.

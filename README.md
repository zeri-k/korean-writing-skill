# Korean Writing Skill

원문의 의미와 기술적 내용을 보존하며 한국어를 작성·교정하는 AI 에이전트 스킬입니다. 문서 작성, 번역, 요약과 상세 문장 교정에 사용합니다.

- 버전: **1.0.8**
- 스킬 이름: `korean-writing`
- 라이선스: [MIT](LICENSE)

## 주요 기능

- 사실, 조건, 수치, 시제와 기술적 의미를 보존합니다.
- 대상과 수행 동작, 근거와 결과의 관계를 명확히 하고 문장과 문단의 연결을 다듬습니다.
- 문서 목적과 예상 독자에 맞춰 용어, 설명 깊이와 형식을 조정합니다.
- 사용자 수정본을 후속 교정의 기준으로 삼고, 불필요한 반복과 강조를 줄입니다.

## 적용 범위

보고서, 기술 문서, PPT 문구와 발표 노트, 매뉴얼, 메일 등의 한국어 작성과 교정에 사용할 수 있습니다. 일반 질의응답이나 단순 맞춤법 확인에는 자동 적용하지 않도록 설명되어 있으며, 스킬을 명시하면 짧은 문장에도 적용할 수 있습니다. 자동 선택 여부는 사용하는 에이전트의 스킬 기능에 따라 달라집니다.

사용자 요청과 문서에 정해진 작성 규칙을 우선합니다.

## 기본 작성 방식

- 설명문은 `~합니다/~습니다`, 규정과 지침은 `~한다`로 작성합니다. 절차는 행동을 설명하고 요청은 정중하게 표현하며, 부탁이나 권고를 의무로 바꾸지 않습니다.
- 기술 용어는 독자에게 통용되는 표기를 사용하고, 필요한 경우 약어와 역할을 설명합니다. 구체적인 권한을 설명할 때는 확인된 권한 이름이나 식별자와 허용 동작을 함께 적습니다.
- 새 설명문에는 em dash와 en dash를 사용하지 않습니다. 문서의 기존 형식과 원문 보존 기준을 따릅니다.

세부 문체와 표기 기준은 [공통 스타일](references/house-style.md)에서 확인할 수 있습니다.

## 설치

### Codex의 프로젝트별 설치

사용할 프로젝트의 루트에서 다음 명령으로 `v1.0.8`을 설치할 수 있습니다. Git이 필요하며, 설치 대상 폴더가 이미 있는 경우에는 기존 내용을 먼저 확인합니다.

```sh
git clone --branch v1.0.8 --depth 1 https://github.com/zeri-k/korean-writing-skill.git .agents/skills/korean-writing
```

설치 결과는 다음과 같습니다.

```text
프로젝트/
└── .agents/
    └── skills/
        └── korean-writing/
            ├── SKILL.md
            └── references/
```

Codex는 프로젝트의 `.agents/skills`에서 로컬 스킬을 탐색합니다. 새 스킬이 표시되지 않으면 Codex를 다시 시작할 수 있습니다. 사용자 전체에 설치하는 경로와 다른 설치 방법은 [공식 스킬 문서](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)에서 확인할 수 있습니다.

다른 AI 에이전트에서 사용할 때는 해당 도구의 `SKILL.md` 지원 여부와 설치 경로를 확인합니다. 스킬 본문과 `references/` 폴더의 상대경로를 유지해야 합니다.

## 사용 예시

### 문장 교정

```text
$korean-writing
아래 문장을 검토해줘. 사실과 기술적 의미는 유지하고,
누가 무엇을 하는지, 어떤 조건에서 가능한지 설명이 빠진 곳은 보완하고,
뜻을 전달하는 데 필요하지 않은 강조는 줄여줘.
```

### 기술 문서 작성

```text
$korean-writing
아래 조사 결과를 개발자 대상 보고서로 작성해줘.
확인된 사실과 추정, 조치 제안과 적용 완료를 구분해줘.
```

### 사용자 수정본을 기준으로 재검토

```text
$korean-writing
내가 수정한 본문을 기준으로 문장 연결을 검토해줘.
수행 시점과 대상 범위를 유지하고, 추가 근거가 필요한 부분은 알려줘.
```

## 파일 구성

[SKILL.md](SKILL.md)는 스킬의 적용 범위와 참조 선택 기준을 담고 있습니다. `references/`에는 문장, 문서 형식, 기술 용어, 근거와 수치 등을 검토하는 세부 기준이 있습니다.

스킬 수정 후 실제 교정 행동을 비교하는 방법과 사례는 [교정 행동 회귀 시험](tests/behavioral/README.md)에 있습니다.

## 버전과 변경 제안

현재 버전은 [VERSION](VERSION), 변경 이력은 [CHANGELOG.md](CHANGELOG.md)에서 확인할 수 있습니다.

변경 제안에는 원문, 의도한 의미와 예상 독자, 문제가 된 표현을 포함하면 판단에 도움이 됩니다.

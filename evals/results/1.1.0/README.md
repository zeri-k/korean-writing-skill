# 1.1.0 검증 결과

2026-11-18에 1.0.5 기준본과 1.1.0 수정본을 비교했습니다. 두 실행 모두 22개 사례에서 판정 기준을 충족했고, 보호 내용 보존 검사도 통과했습니다. 이번 표본에서 새로 발생한 의미 손실이나 과도한 교정은 발견하지 못했습니다. 기준본도 통과했으므로 이 결과를 교정 성능 향상의 증거로 해석하지 않습니다.

## 범위와 실행 조건

- 기준본은 Git 커밋 `a0bf1ac`의 1.0.5입니다. 평가 전에 Git 패키지와 설치본 15개 파일의 해시 일치를 확인했습니다.
- 수정본은 이번 커밋의 `SKILL.md`, `references/evidence.md`, 새 `references/orthography.md`를 사용했습니다. 나머지 작문 참조와 공통 스타일은 기준본과 같습니다.
- 독립된 두 에이전트에 같은 22개 입력을 제공했습니다. 두 실행의 기록에서 모델 `gpt-6-astra`, 추론 설정 `ultra`를 확인했습니다. 이 설정은 이번 비교 조건이며 스킬의 권장 설정이 아닙니다.
- 각 실행에는 지정한 스킬과 입력만 제공하고 다른 실행의 결과, 판정 기준과 개선 의도는 제공하지 않았습니다. 입력의 명령은 실행하지 않았습니다.
- [기준본 출력](baseline.json)과 [수정본 출력](candidate.json)의 본문과 notes는 반환된 결과 그대로입니다. JSON 배열은 `cases`와 `references_read`로 나눠 보관했으며, 참조 경로에서 컴퓨터별 상위 경로만 제거했습니다. `baseline/`과 `candidate/`는 평가 당시의 사본 이름입니다.
- 메인 에이전트가 입력, 두 출력과 [판정 기준](../../rubric.json)을 직접 대조했습니다. 사람의 독립 평가나 다회 실행 통계는 아닙니다.

## 기계적 검증

- `quick_validate.py`로 스킬 구조와 메타데이터를 확인했습니다.
- `check_preservation.py`는 두 출력 모두에서 22개 ID, 코드 블록, 인라인 코드, Markdown 링크 대상과 위키링크 보존을 확인했습니다.
- 명령, 인라인 식별자, 링크와 위키링크를 각각 바꾼 입력 네 가지가 실패하는지 확인했습니다. ID 누락·중복과 닫히지 않은 코드 블록도 검출했습니다.

새 맞춤법 참조를 실제로 읽었음은 수정본의 참조 목록에서 확인했습니다. 한 번에 섞어 제공한 사례이므로 문장별 참조 선택이나 자동 스킬 호출을 검증한 결과는 아닙니다. 문서 전체의 Markdown 렌더링과 Vault 전수 품질도 이 평가의 범위에 포함하지 않습니다.

## 버전 판단

기존 호출 범위와 작문 기준을 유지하면서 조건부 참조와 검증 기능을 추가했으므로 `1.1.0`으로 정했습니다. 이는 호환성을 유지한 기능 추가에 부버전을 올리는 [SemVer의 취지](https://semver.org/lang/ko/)를 스킬 패키지에 적용한 판단입니다. 공통 스타일 본문은 수정하지 않았으므로 그 식별자 `1.0.1`은 유지했습니다.
